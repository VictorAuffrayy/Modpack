Applied Energistics 2

AE2 est le stockage le plus puissant du pack, et le plus exigeant : tout tourne autour des canaux. Une fois qu'on a compris combien chaque câble en transporte, le reste suit.

Vérifié sur : Applied Energistics 2 19.2.18 + config/ae2-common.toml d'ATM10

Les canaux

Presque chaque appareil branché au réseau (terminal, interface, bus, lecteur de cellules…) consomme un canal. ATM10 garde le mode de canaux par défaut d'AE2.

Les règles

  • Câble normal (glass, covered, smart) : 8 canaux.
  • Câble dense : 32 canaux. Chaque face du contrôleur en fournit 32.
  • Sans contrôleur, un réseau tourne quand même, mais limité à 8 appareils en tout.
  • Le bon réflexe : du câble dense qui part du contrôleur, puis du câble normal pour les groupes de 8 machines.

Sources : GridNode.getMaxChannels · ChannelMode.java · ATM10 config/ae2-common.toml

Le contrôleur

Les règles

  • Plusieurs blocs de contrôleur collés forment un seul contrôleur. La structure ne doit pas dépasser 7 blocs sur chaque axe.
  • Tous les blocs de contrôleur du réseau doivent se toucher, sinon le réseau passe en conflit.
  • Pas de croix : si un bloc a des contrôleurs des deux côtés sur deux axes à la fois (par exemple nord-sud et est-ouest), le réseau passe en conflit. Les lignes, les plaques et les angles sont permis.

Sources : ControllerValidator.java

Les cellules de stockage

Une cellule a deux limites : ses octets et son nombre de types. Chaque type différent coûte des octets avant même de stocker un objet, donc une cellule pleine de 63 objets différents en contient beaucoup moins qu'on croit.

Les règles

  • 1k = 1024 octets, 4k = 4096, 16k = 16 384, 64k = 65 536, 256k = 262 144.
  • 1 octet = 8 objets, ou 8 seaux pour les fluides.
  • Cellules d'objets : 63 types max. Cellules de fluides : 18 types max.
  • Coût de chaque type : 8 octets (1k), 32 (4k), 128 (16k), 512 (64k), 2048 (256k). Exemple : une 1k avec un seul type garde (1024 − 8) × 8 = 8128 objets.

Sources : AEItems.java · StorageTier.java · AEKeyType.getAmountPerByte

Le CPU de craft

Les règles

  • Un pavé plein (sans trou) de blocs de craft : Crafting Unit, Crafting Storage, Co-Processing Unit, Crafting Monitor.
  • Au moins un Crafting Storage, sinon le CPU ne se forme pas.
  • 17 blocs maximum sur chaque axe.

Sources : CraftingCPUCalculator.java
