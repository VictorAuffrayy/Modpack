Refined Storage

ATM10 embarque Refined Storage 2, une réécriture complète du mod. Beaucoup de guides en ligne parlent encore de la version 1 : les tailles de disques et l'autocraft ont changé.

Vérifié sur : Refined Storage 2.0.9 + config/refinedstorage-common.toml d'ATM10

Ce qui change par rapport à AE2

Les règles

  • Pas de canaux : on branche autant d'appareils qu'on veut sur un câble.
  • Les câbles ne consomment rien (énergie à 0 dans ATM10). Le contrôleur stocke 50 000 FE.
  • Chaque appareil a sa consommation : 10 FE/t pour un Disk Drive plus 4 par disque, 14 pour une Crafting Grid, 16 pour un Wireless Transmitter (valeurs d'ATM10).
  • Le Wireless Transmitter couvre 16 blocs, +8 par Range Upgrade.

Sources : ATM10 config/refinedstorage-common.toml

Disques de stockage

Contrairement à AE2, il n'y a pas de limite de types : un disque 1k garde 1024 objets, qu'ils soient tous identiques ou tous différents.

Les règles

  • Objets : 1k = 1024, 4k = 4096, 16k = 16 384, 64k = 65 536 objets.
  • Fluides : 64, 256, 1024 et 4096 seaux.
  • Pour plus gros, ATM10 inclut ExtraStorage.

Sources : ItemStorageVariant.java · FluidStorageVariant.java

Autocraft

Les règles

  • Les patterns se fabriquent dans la Pattern Grid et se rangent dans un Autocrafter : 9 patterns par Autocrafter.
  • On peut enchaîner jusqu'à 8 Autocrafters les uns derrière les autres pour qu'ils partagent la même machine cible.

Sources : AutocrafterBlockEntity.java
