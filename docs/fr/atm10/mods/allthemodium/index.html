Allthemodium

Allthemodium, Vibranium puis Unobtainium : les trois métaux qui rythment la fin de partie d'ATM10. Chaque palier d'équipement demande un template de forge, et chaque template se trouve dans un endroit différent.

Vérifié sur : Allthemodium 3.2.1 (branche 1.21.x) + scripts KubeJS et livre de quêtes d'ATM10

Sommaire

  1. Où trouver les templates

Où trouver les templates

Les règles

  • Template Allthemodium : en brossant de l'argile suspecte (Suspicious Clay), dans le sol des Ancient Cities. Le bloc le donne à 100 %.
  • Template Vibranium : en brossant du sable des âmes suspect (Suspicious Soul Sand), dans les Bastions du Nether. Lui aussi à 100 %.
  • Template Unobtainium : pas d'archéologie. Il vient des Trial Spawners des salles « library » du Dungeon, dans la dimension The Other.
  • Avec Lootr, les blocs suspects donnent leur loot à chaque joueur, comme les coffres.

Sources : loot_table/arch.json, arch2.json, chest/template.json · ATM10 quêtes : chapitre Allthemodium

Dupliquer un template

Une fois le premier template trouvé, on n'en cherche plus : chaque template se copie à l'établi, 1 donne 2. Chacun a sa propre recette.

La chaîne

  1. Template Allthemodium1 template + 7 lingots de netherite + 1 deepslate → 2 templates
  2. Template Vibranium1 template + 7 lingots d'Allthemodium + 1 Ancient Stone → 2 templates
  3. Template Unobtainium1 template + 7 lingots de Vibranium + 1 pierre de l'End → 2 templates

Sources : recipe/smithing/*_upgrade_smithing_template.json

L'ordre des améliorations

Les règles

  • Netherite → Allthemodium : outil en netherite + template Allthemodium + lingot d'Allthemodium, à la table de forge.
  • Allthemodium → Vibranium : outil en Allthemodium + template Vibranium + lingot de Vibranium.
  • Vibranium → Unobtainium : outil en Vibranium + template Unobtainium + lingot d'Unobtainium.
  • ATM10 ajoute aussi des « plaques silencieuses » qui passent par les mêmes templates (plaque + template + lingot du palier d'avant).

Sources : recipe/smithing/*_pickaxe_smithing.json · ATM10 kubejs/.../Allthemodium/Recipes.js
