D'où viennent les données

Chaque guide est vérifié dans le code du mod, à la version du pack, et cite ses sources. Quand le pack change de version, un script relit les fichiers.

Le chat de chaque mod est un assistant IA (Claude). Il s'appuie sur le guide quand il existe ; sinon, il le dit et te conseille de vérifier en jeu.

Site fait par un fan, sans lien avec l'équipe All the Mods, Mojang ni les auteurs des mods.
