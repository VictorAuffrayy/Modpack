Applied Energistics 2

AE2 is the most powerful storage in the pack, and the most demanding: everything revolves around channels. Once you know how many each cable carries, the rest follows.

Channels

Almost every device on the network (terminal, interface, bus, drive…) uses one channel. ATM10 keeps AE2's default channel mode.

The rules

  • Normal cable (glass, covered, smart): 8 channels.
  • Dense cable: 32 channels. Each controller face provides 32.
  • Without a controller a network still works, but with 8 devices at most.
  • Rule of thumb: dense cable out of the controller, then normal cable for groups of 8 machines.

Sources: GridNode.getMaxChannels · ChannelMode.java · ATM10 config/ae2-common.toml

The controller

The rules

  • Several controller blocks touching form one controller. The structure can't exceed 7 blocks on any axis.
  • All controller blocks on the network must touch each other, otherwise the network goes into conflict.
  • No crosses: if a block has controllers on both sides along two axes at once (say north-south and east-west), the network goes into conflict. Lines, slabs and corners are fine.

Sources: ControllerValidator.java

Storage cells

A cell has two limits: bytes and number of types. Each new type costs bytes before storing anything, so a cell full of 63 different items holds far less than you'd think.

The rules

  • 1k = 1024 bytes, 4k = 4096, 16k = 16,384, 64k = 65,536, 256k = 262,144.
  • 1 byte = 8 items, or 8 buckets for fluids.
  • Item cells: 63 types max. Fluid cells: 18 types max.
  • Cost per type: 8 bytes (1k), 32 (4k), 128 (16k), 512 (64k), 2048 (256k). Example: a 1k with a single type holds (1024 − 8) × 8 = 8128 items.

Sources: AEItems.java · StorageTier.java · AEKeyType.getAmountPerByte

The crafting CPU

The rules

  • A solid box (no gaps) of crafting blocks: Crafting Units, Crafting Storage, Co-Processing Units, Crafting Monitors.
  • At least one Crafting Storage, otherwise the CPU won't form.
  • 17 blocks at most on each axis.

Sources: CraftingCPUCalculator.java
