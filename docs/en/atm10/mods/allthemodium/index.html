Allthemodium

Allthemodium, then Vibranium, then Unobtainium: the three metals that pace ATM10's late game. Each gear tier needs a smithing template, and each template comes from a different place.

Checked against: Allthemodium 3.2.1 (branche 1.21.x) + scripts KubeJS et livre de quêtes d'ATM10

Contents

  1. Where to find the templates
  2. Duplicating a template
  3. Upgrade order

Where to find the templates

The rules

  • Allthemodium template: brush Suspicious Clay in the floors of Ancient Cities. The block always gives it.
  • Vibranium template: brush Suspicious Soul Sand in Nether Bastions. Also a 100% drop.
  • Unobtainium template: no archaeology. It comes from the Trial Spawners in the Dungeon's library rooms, in The Other dimension.
  • With Lootr, suspicious blocks give their loot to each player, like chests.

Sources: loot_table/arch.json, arch2.json, chest/template.json · ATM10 quêtes : chapitre Allthemodium

Duplicating a template

Once you've found the first template, you never need to look again: each one copies at the crafting table, 1 makes 2. Each has its own recipe.

The chain

  1. Allthemodium template1 template + 7 netherite ingots + 1 deepslate → 2 templates
  2. Vibranium template1 template + 7 Allthemodium ingots + 1 Ancient Stone → 2 templates
  3. Unobtainium template1 template + 7 Vibranium ingots + 1 end stone → 2 templates

Sources: recipe/smithing/*_upgrade_smithing_template.json

Upgrade order

The rules

  • Netherite → Allthemodium: netherite tool + Allthemodium template + Allthemodium ingot, at the smithing table.
  • Allthemodium → Vibranium: Allthemodium tool + Vibranium template + Vibranium ingot.
  • Vibranium → Unobtainium: Vibranium tool + Unobtainium template + Unobtainium ingot.
  • ATM10 also adds "silent plates" that use the same templates (plate + template + previous tier's ingot).

Sources: recipe/smithing/*_pickaxe_smithing.json · ATM10 kubejs/.../Allthemodium/Recipes.js
