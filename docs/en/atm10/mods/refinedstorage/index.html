Refined Storage

ATM10 ships Refined Storage 2, a full rewrite of the mod. Many guides online still describe version 1: disk sizes and autocrafting have changed.

Checked against: Refined Storage 2.0.9 + config/refinedstorage-common.toml d'ATM10

How it differs from AE2

The rules

  • No channels: plug in as many devices as you like on one cable.
  • Cables use no energy (0 in ATM10). The controller stores 50,000 FE.
  • Each device has its own draw: 10 FE/t for a Disk Drive plus 4 per disk, 14 for a Crafting Grid, 16 for a Wireless Transmitter (ATM10 values).
  • The Wireless Transmitter reaches 16 blocks, +8 per Range Upgrade.

Sources: ATM10 config/refinedstorage-common.toml

Storage disks

Unlike AE2 there's no type limit: a 1k disk holds 1024 items, whether they're all the same or all different.

The rules

  • Items: 1k = 1024, 4k = 4096, 16k = 16,384, 64k = 65,536 items.
  • Fluids: 64, 256, 1024 and 4096 buckets.
  • For bigger disks, ATM10 includes ExtraStorage.

Sources: ItemStorageVariant.java · FluidStorageVariant.java

Autocrafting

The rules

  • Make patterns in the Pattern Grid and put them in an Autocrafter: 9 patterns per Autocrafter.
  • Up to 8 Autocrafters can be chained one behind another so they share the same target machine.

Sources: AutocrafterBlockEntity.java
